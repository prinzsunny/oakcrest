🦉 Why do we learn coding?

Code is a list of clear steps that a computer follows exactly. Learning to code teaches us to break a big job into small steps, find mistakes and fix them.

  • 🚦Traffic lights change by rules
  • 🥪A recipe is steps in order
  • 🧺A washing machine runs a program
  • 📱Every app is code
